# BUYOH Payroll System — UI/UX Design

## 1. UI/UX Overview

The BUYOH Payroll System interface should be simple, clean and professional.

The goal is to allow payroll users to complete tasks quickly without confusion.

The design will use:

- HTML
- CSS
- Bootstrap
- Simple JavaScript
- Responsive layouts

---

## 2. Design Principles

The interface should be:

- Easy to navigate
- Secure
- Business-like
- Mobile-friendly where practical
- Clear with payroll figures
- Consistent across all pages

---

## 3. Main Screens

The system will include the following screens:

1. Login Page
2. Dashboard
3. Employee List
4. Add Employee
5. Edit Employee
6. Departments
7. Payroll Periods
8. Process Payroll
9. Payroll Review
10. Payslip Preview
11. Reports
12. User Management
13. Settings
14. Audit Logs
