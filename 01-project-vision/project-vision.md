# BUYOH Payroll System — Project Vision

## Purpose

The BUYOH Payroll System is an internal payroll management application designed to help BUYOH calculate salaries, deductions, net pay, payslips, and payroll reports accurately and securely.

## Main Goal

To replace manual payroll calculations with a structured system that can:

- Store employee salary information
- Calculate NSSA, PAYE, AIDS levy, overtime, allowances, and deductions
- Generate monthly payroll records
- Produce employee payslips
- Export payroll reports
- Secure payroll data with user login and role-based access
- Support future deployment on Ubuntu Server, Docker, and AWS

## Target Users

1. Admin  
2. Payroll Officer  
3. Manager / Viewer  

## First Version Scope

The first version will include:

- Employee management
- Payroll calculation
- NSSA calculation
- PAYE calculation
- AIDS levy calculation
- Payslip generation
- Payroll reports
- User login
- Basic role permissions
- PostgreSQL database
- Docker deployment

## Future Scope

Future improvements may include:

- AWS migration
- S3 payslip storage
- Emailing payslips to employees
- Leave management
- Attendance integration
- ZIMRA-ready reports
- Audit dashboard
- Multi-branch support

## Success Criteria

The system will be considered successful when BUYOH can:

- Add employees
- Run monthly payroll
- Calculate correct net salaries
- Generate payslips
- Export payroll reports
- Securely access payroll data
- Back up payroll records
