## Project Goal

The goal of this project is to build a secure and reliable payroll management platform that can process employee salaries, statutory deductions, payroll reports and payslips.

The system is being designed with future SaaS potential, meaning it can later evolve from a single-company payroll system into a multi-company payroll platform.

## Planned Technology Stack

- Frontend: HTML, CSS, Bootstrap
- Backend: Python Flask
- Database: PostgreSQL
- Authentication: Flask-Login
- PDF Generation: WeasyPrint
- Web Server: NGINX
- App Server: Gunicorn
- Deployment: Docker
- Operating System: Ubuntu Server
- Future Cloud: AWS EC2, RDS, S3, Route 53, CloudWatch
